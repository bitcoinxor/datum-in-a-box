# Docker variant — work in progress

This directory is a design sketch for a Docker-packaged version (node + gateway as two
containers, bootstrapped from a chain snapshot). **The images are not published yet and
this does not work today.** Use the native install at the repository root instead:
`setup-datum.sh`, or the manual steps in the top-level README.

`README-sketch.md` and `DESIGN.md` are the original notes and are kept for reference.
